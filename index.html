    实时行情：加密用 Binance、A股用腾讯、期货用新浪公开接口，前端直连（JSONP / CORS）。
    行情接口若被拦截或超时，会自动回退模拟，不至于白屏。

    大模型 API 设置

    示例：DeepSeek https://api.deepseek.com/v1 + deepseek-chat； OpenAI https://api.openai.com/v1 + gpt-4o-mini； 通义 https://dashscope.aliyuncs.com/compatible-mode/v1 + qwen-plus。 Key 仅存浏览器本地。
    若浏览器直连被 CORS 拦截，把 Base URL 换成你自己的代理地址即可。
