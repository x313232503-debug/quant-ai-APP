# QuantAI · 量化 AI 股票期货终端（实时版）

纯前端单页应用，单文件 `index.html`，零依赖、零构建。

## 功能
- 实时行情：加密(Binance) / A股(腾讯) / 期货(新浪)，纯前端直连；接口异常自动回退模拟
- 多因子信号：趋势 / 动量 / MACD / 布林 / 量能，加权评分，可解释
- 策略回测：收益 / 最大回撤 / 夏普 / 胜率 / 交易次数 / 对比买入持有
- 大模型解读：OpenAI 兼容接口（Base URL + Key + 模型），Key 仅存浏览器本地
- 手机竖屏自适应
